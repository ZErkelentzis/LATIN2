# Self-Contained Casestudies Used in Papers

- One folder per casestudy with naming convention `yyyy-<some abbreviation for the paper>`.

  The abbreviation must reflect the paper's contents (e.g. `2021-softening` for the paper on the softening operator). In contrast, any names of conferences or journals *must not* be used.
- Every folder must contain a README and should link to the corresponding published paper or preprint.
- MMT Formalizations must be self-contained. They *must not* reference anything from LATIN elsewhere.
- If a casestudy consists of multiple files, it is recommended to employ some naming scheme that automatically sorts the files in alphabetic order (e.g., use `1-basics.mmt`, `2-library.mmt`, `3-softening.mmt`).
